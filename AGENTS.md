# Website editing

Use the Humanizer writing guidelines in COPY_STYLE.md for product, support and
explanatory prose. Keep all facts, legal meaning, support details and URL routes
intact. Clear labels need no rewrite. Do not invent availability, testimonials,
usage numbers, financial outcomes or privacy claims.

Product copy lives in build_home.py. Regenerate all pages with python build_site.py. Navigation and footer live in layout.py.
Keep this repository limited to static public material. Do not add private app
source, credentials, user records or internal release documents.
